# Ticket Tycoon for Android (test builds)

Run your own IT support company across the UK: fix the printer (again), bill the job cards, hire your team and open branches from Wokingham to Edinburgh. Made by [Coffee Cup Solutions](https://coffeecupsolutions.com).

## Install the latest test build

1. On your Android phone, open the **[latest release](../../releases/latest)** and tap the `.apk` file to download it.
2. Open the download. If Android asks, allow your browser (or Files app) to **install unknown apps**, then tap **Install**.
3. To update later, download the newer `.apk` from the same link and install it over the top. Your progress is kept.

Needs Android 7.0 or newer. No ads, no in-app purchases, no data collected ([privacy policy](https://coffeecupsolutions.com/privacy-policy)).
